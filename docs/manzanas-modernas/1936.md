# Manzanas completas de 1936

La época conserva exactamente las 885 manzanas de 1911 y sus 6009 casas. Añade 6195 unidades con 9418 casas: 7080 unidades y 15427 casas generadas. El cambio sigue el modelo y la paleta aprobados en 1772–1889; las cantidades son una interpretación visual, no un censo histórico.

## Continuidad y fuentes

El procedimiento y sus límites están en [1911.md](1911.md). Usa la ocupación por época ya documentada por el pipeline y las caras de calles de 1936; no vuelve a interpretar escaneos ni afirma reconstruir lotes privados. Solo las unidades nuevas reciben el retiro visual adicional de 1 m. No se vuelve a reducir lo heredado. Patios, jardines y solares usan el mismo `verdeCiudad` y saturación 0,48; los tres campos anteriores permanecen intactos. Todas las nuevas manzanas incluyen árboles. Los edificios con modelo conservan su posición y sus reservas.

Los planos y sus fichas se conservan en `fuentes/`: [1936, MOP/DCN](https://archive.org/details/WCWdb_18053) y [plano catalogado hacia 1950, levantado con fotografías aéreas de 1946](https://archive.org/details/WCWdb_18051). Ambas fichas registran licencia no indicada y dominio público dudoso; se reutilizan los derivados existentes, sin incorporar nuevos escaneos ni afirmar una licencia nueva. La agrupación en solares, su densidad y su arbolado son decisiones de representación solicitadas por el responsable, no información catastral contenida en esas fuentes. La división por calles fuera de la red de referencia solo junta huellas contiguas. Las reservas de hitos no incorporan modelos pendientes.

Véanse `auditoria-1936.json` y `continuidad-1936.txt`: contención, solapes, copas, semillas, árboles e identidad de las otras seis épocas. Esta comprobación geométrica no cierra por sí sola R1–R12 ni la herramienta histórica global pendiente. Las capturas son revisión automatizada; la prueba humana sigue pendiente.

## Instalación y publicación

Esta rama depende de la de 1911; fusionar en orden 1911 → 1936 → 1946. Con los escaneos y derivados del proyecto disponibles:

```sh
npm run datos -- --desde retiro-1936
npm run datos -- --verificar
npm run dev
```

Revisar las siete épocas, el modo color, tinta y los hitos. Los binarios quedan fuera de git. Tras fusionar y revisar el paquete regenerado, `npm run datos:publicar` publica los datos y solicita Pages. El PR no actualiza por sí solo los datos de producción.

## Casos geométricos y validación

El retiro se aplica donde la geometría permite conservar un solar válido; las excepciones quedan en el informe. Se descartaron 11 franjas cuyo ancho útil tras el retiro era inferior al mínimo del generador. No se ocultan como manzanas terminadas. El índice espacial evita unir de nuevo toda la ciudad por cada referencia y su regresión compara el resultado con el método anterior.

La auditoría verifica 6195 unidades nuevas con árboles, cero casas fuera de sus contornos y cero copas sobre tejados. El solape numérico entre solares es 0,000001 m², bajo la tolerancia geométrica de 0,01 m². Las otras seis épocas conservan exactamente casas y árboles; el archivo adicional de árboles de 1946 también permanece idéntico. `npm run datos -- --verificar` pasa.

Validación local: 1806 tests Vitest, 1033 tests Python y 108 pruebas Playwright aprobadas (1 omitida); build y presupuesto del JavaScript inicial aprobados.
